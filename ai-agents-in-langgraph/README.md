# 🤖 AI Agents in LangGraph

Этот репозиторий содержит материалы, код и конспекты на основе курса **"AI Agents in LangGraph"** (созданного в партнерстве LangChain, Tavily и DeepLearning.AI).

LangChain — популярный open-source фреймворк для создания LLM-приложений, который недавно представил **LangGraph**. Это мощное расширение позволяет разработчикам создавать сложные, циклические и легко контролируемые ИИ-агенты на основе архитектуры графов.

## 🎯 О проекте и курсе

В этом проекте мы проходим путь от написания базового агента на чистом Python до разработки сложных многошаговых ИИ-приложений, способных планировать задачи, искать информацию в интернете, исправлять собственные ошибки и взаимодействовать с человеком.

### 📚 Чему посвящен этот репозиторий:

* 🛠 **Агент с нуля:** Построение базового агента (паттерн ReAct) с использованием Python и LLM. Разбор того, какие задачи выполняет нейросеть, а какие — код (runtime).
* 🕸 **Внедрение LangGraph:** Перенос самодельного агента на компоненты LangGraph. Изучение узлов (nodes), ребер (edges), условных переходов и графов состояний (StateGraph) для создания потоковых (flow-based) приложений.
* 🔍 **Агентский поиск (Agentic Search):** Работа с поисковыми системами нового поколения (Tavily). В отличие от традиционных поисковиков, возвращающих ссылки, агентский поиск выдает множественные ответы в предсказуемом формате (JSON), обогащая знания агента свежими данными.
* 💾 **Персистентность (Persistence):** Управление состоянием (state management) агента. Настройка памяти для работы с несколькими потоками (threads), переключение между диалогами и «путешествие во времени» (возможность загрузки и редактирования предыдущих состояний).
* 🙋‍♂️ **Человек в цикле (Human-in-the-loop):** Внедрение механизмов прерывания (breakpoints) для ручного контроля, одобрения критических действий агента и корректировки его пути.
* ✍️ **Финальный проект (Essay Writer):** Разработка комплексного агента для написания эссе, который полностью имитирует рабочий процесс исследователя: *Планирование -> Поиск -> Написание черновика -> Рефлексия/Критика -> Дополнительный поиск -> Финальная доработка*.

## 🛠 Технологический стек

* **Язык:** Python 3
* **Оркестрация:** [LangChain](https://www.langchain.com/) & [LangGraph](https://python.langchain.com/docs/langgraph)
* **LLM:** OpenAI API (GPT-3.5-turbo / GPT-4o)
* **Поиск:** [Tavily Search API](https://tavily.com/)
* **Среда:** Jupyter Notebook
